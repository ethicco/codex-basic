## [C] Контекст

Мы переходим к созданию точек мониторинга для сайтов

## [0] Результат / Цель - что должно быть

Пользователь на главном экране нажимает Добавить сайт, вводит форму появившийся URL для мониторинга, а также частота опроса. Например, мы можем задать ему каждые 5 секунд, каждую минуту и каждый час, чтобы можно было выбрать периодичность. Нажимает Создать. После этого на главной странице отображается создание точки мониторинга

## [S] Границы

Не делаем сам мониторинг, пока просто создаем точку.

## [T] Проверка - когда готово

Тесты сделаны и точка создалась.
